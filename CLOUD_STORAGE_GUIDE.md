# Cloud Storage Guide

Simple, working cloud backup solutions for your Anaesthetic Logbook - **no complex setup required**.

## 🎯 Quick Recommendation

**For most users:** Use **Email Backup** weekly. It's simple, reliable, and works on all devices.

**For iOS users:** Use **Save to Files** → iCloud Drive for automatic sync.

**For Android users:** Use **Save to Files** → Google Drive folder for automatic sync.

---

## ✅ Working Solutions (Choose One)

### Option 1: Email Backup (Recommended for Most Users)

**Best for:** Everyone, especially those who want simplicity and reliability

#### How It Works

1. Open the Anaesthetic Logbook app
2. Go to **Export** tab
3. Click **"📧 Email Backup"** button
4. Your email app opens with:
   - Subject: "Anaesthetic Logbook Backup - [Date]"
   - Attached: Your logbook as a JSON file
   - Body: Summary of your cases
5. Send the email to yourself
6. Done! Your backup is now in Gmail/Outlook cloud storage

#### Why This is Great

✅ **Automatic cloud storage**
- Gmail users: Backup is in Google Drive
- Outlook users: Backup is in OneDrive
- Yahoo/Others: Backup is in email cloud

✅ **Searchable**
- Find backups: Search "subject:anaesthetic logbook"
- Find by date: "subject:backup after:2026/01/01"

✅ **Version history**
- Each email is a snapshot
- Keep monthly backups
- Roll back to any date

✅ **Supervisor sharing**
- CC or forward to supervisor
- Perfect for verification
- Timestamped by email

✅ **Works everywhere**
- iOS, Android, Desktop
- No browser restrictions
- No special permissions needed

#### Setup Time: 0 minutes

#### Cost: Free

---

### Option 2: Save to Files (Best for Mobile Users)

**Best for:** iPhone/iPad users with iCloud, Android users with Google Drive

#### How It Works

**On iPhone/iPad:**
1. Go to **Export** tab
2. Click **"💾 Save to Files"** button
3. Tap **"iCloud Drive"** in the file picker
4. Choose a folder (e.g., "Documents")
5. Tap **Save**
6. Done! File syncs automatically to iCloud

**On Android:**
1. Go to **Export** tab
2. Click **"💾 Save to Files"** button
3. File downloads to Downloads folder
4. Open **Files** app
5. Move file to **Google Drive** folder
6. Done! File syncs automatically

**On Desktop:**
1. Go to **Export** tab
2. Click **"💾 Save to Files"** button
3. Choose your cloud folder (Dropbox, OneDrive, Google Drive)
4. Click **Save**
5. Done! File syncs via desktop app

#### Why This is Great

✅ **Native integration**
- Uses your phone's built-in file system
- Familiar interface
- Standard cloud sync

✅ **Automatic sync**
- Save once, available everywhere
- Background sync when connected
- No manual upload needed

✅ **Organized**
- Keep all backups in one folder
- Easy to find
- Can organize by month/year

✅ **Works offline**
- Save while offline
- Syncs when connected
- Always have local copy

#### Setup Time: 0 minutes (if you already use iCloud/Google Drive)

#### Cost: Free (with your existing cloud plan)

### What Gets Backed Up

✅ Regional block details

✅ Supervision information

### What Doesn't Get Backed Up

✅ **Email backups:** Stored in email cloud, encrypted in transit

✅ **No patient data:** App designed for anonymized data only
✅ **GDPR compliant:** You own and control all data

- **JSON file size:** Typically 100-500 KB for 1000 cases
- **Email attachment limits:** Gmail allows 25 MB (plenty!)
- **Cloud storage:** Minimal - thousands of cases = a few MB

## 🆘 Troubleshooting

### "Email Backup" Button Does Nothing (iPhone)
**Solution:** Make sure Mail app is set up
1. Settings → Mail → Accounts
2. Add your email account if missing
3. Try again

**Alternative:** Use "Save to Files" instead

### Can't Find Downloaded File (Android)
**Location:** Downloads folder
1. Open "Files" app (or "My Files")
2. Look in "Downloads"
3. File name: `anaesthetic-logbook-[date].json`

### File Won't Import
**Check:**
- File is `.json` format
- File not corrupted (try opening in text editor)
- Using correct "Import Data" button
- Browser allows file selection

#### Google Drive Setup

1. **Create Google Cloud Project**
   - Go to https://console.cloud.google.com
   - Create new project: "Anaesthetic Logbook"
   
2. **Enable Google Drive API**
   - In APIs & Services → Library
   - Search "Google Drive API"
   - Click Enable

3. **Create OAuth Credentials**
   - APIs & Services → Credentials
   - Create OAuth 2.0 Client ID
   - Application type: Web application
   - Authorized origins: Your app URL
   - Authorized redirect URIs: Your app URL + `/callback`

4. **Get Credentials**
   - Copy Client ID
   - Copy Client Secret

5. **Add to App**
   ```javascript
   const GOOGLE_CLIENT_ID = 'your-client-id-here';
   const GOOGLE_CLIENT_SECRET = 'your-secret-here';
   const REDIRECT_URI = 'your-app-url/callback';
   ```

6. **Implement OAuth Flow**
   - See `cloud-oauth-example.js` for implementation
   - Handle token refresh
   - Store tokens securely

#### Dropbox Setup

1. **Create Dropbox App**
   - Go to https://www.dropbox.com/developers/apps
   - Create app → Scoped access
   - Choose "Full Dropbox" or "App folder"
   - Name: "Anaesthetic Logbook"

2. **Configure OAuth**
   - Add redirect URI
   - Set permissions: `files.content.write`, `files.content.read`

3. **Get Credentials**
   - Copy App key
   - Copy App secret

4. **Implement**
   ```javascript
   const DROPBOX_CLIENT_ID = 'your-app-key';
   const DROPBOX_CLIENT_SECRET = 'your-app-secret';
   ```

#### Box Setup

1. **Create Box App**
   - Go to https://app.box.com/developers/console
   - Create New App → Custom App
   - Authentication: OAuth 2.0 with JWT

2. **Configure**
   - Add redirect URI
   - Set scopes: Read and write all files

3. **Get Credentials**
   - Copy Client ID
   - Copy Client Secret

### 📋 To Implement (If You Set Up OAuth)

Replace the placeholder functions in the app with actual OAuth flows:

```javascript
// Example: Real Google Drive upload
async function uploadToGoogleDrive(data) {
    const metadata = {
        name: cloudConfig.fileName,
        mimeType: 'application/json'
    };
    
    const form = new FormData();
    form.append('metadata', new Blob([JSON.stringify(metadata)], {type: 'application/json'}));
    form.append('file', new Blob([data], {type: 'application/json'}));
    
    const response = await fetch('https://www.googleapis.com/upload/drive/v3/files?uploadType=multipart', {
        method: 'POST',
        headers: {
            'Authorization': `Bearer ${cloudConfig.accessToken}`
        },
        body: form
    });
    
    if (!response.ok) throw new Error('Upload failed');
    return await response.json();
}
```
